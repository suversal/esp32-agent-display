# Claude Code 接入验证

验证日期：2026-10-14 至 2026-10-15（Asia/Shanghai）。

## 当前结果

- 本机 Claude Code 版本：2.1.299。
- 临时会话 settings 中的观察 hooks 实际触发，bridge 收到 session_start、turn_start、session_end。
- 观察 hook 没有返回授权决定；捕获到的 hook 记录没有非零退出码。
- 模型请求连续返回 HTTP 429，随后由验证脚本按超时上限终止测试会话。因此 Read 调用、PostToolUse、Stop 正常完成、人工授权、拒绝和子代理链路尚未通过真实客户端验收。
- 没有修改当前模型服务地址、凭据或模型配置，也没有继续重复请求。

M1 的代码原型和自动化验证已具备，但不能据此把完整 M1 人工端到端验收标成通过。

## 自动与运行时验证

52 项测试全部通过，包括：

- 状态生命周期、轮次隔离、并行子代理和相同调用的歧义。
- 授权先到、工具开始迟到，以及第二个迟到候选撤销绑定。
- 完成事件先到、旧工具事件后到；会话结束墓碑及恢复会话。
- 延迟的 SessionStart 不清除已经观察到的等待状态。
- 授权只响一次；ack 不批准、不解除等待；安静时段。
- 保存并重启后恢复 stale 等待，旧提醒保持静默。
- 配置追加、重复安装、卸载往返，保留其他 hooks 和安装后新增设置。
- HTTP/WS、token 校验、本机接口限制、异常和超大 payload 的静默丢弃。
- 后台 curl 转发约 90 KiB 的 stdin；ps 参数列表不含测试 payload。

在实际启动的服务上另行验证了：

- WebSocket 成功连接，首帧含 current_sound_seq。
- 三个一次性模拟会话分别显示 waiting、running、done。
- ack 经 WebSocket 往返生效。
- 临时模拟会话随后被清理，没有当成真实编程助手会话保留。

安装后的中继脚本返回时间，每种情况各采样 8 次：

| bridge 状态 | 中位数 | 最大值 |
|---|---|---|
| 运行中 | 5.77 ms | 6.57 ms |
| 不可用 | 5.51 ms | 6.38 ms |

这些数字是中继进程返回时间，不是模型延迟或设备显示/声音延迟。设备尚未接入。
